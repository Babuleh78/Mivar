# Excel to Mivar XML

Данный код представляет собой программу для преобразования Excel документа в XML документ, пригодный для использования в **КЭСМИ Наука**.

На текущий момент реализованы лабораторные работы №1 и №2. Готовый к запуску `.exe` файл можно найти в папке `dist`.

## Описание работы

Программа решает проблему дублирования формул в базе знаний. Например, если добавить отношение `q = C * U`, то при известных `C` и `q` среда КЭСМИ не сможет найти значение `U` (пока в базу не будет добавлено обратное отношение `U = q / C`).

Благодаря данной программе необходимость в ручном добавлении всех возможных комбинаций формул отпадает. Утилита автоматически генерирует необходимые обратные зависимости и добавляет их в итоговый XML файл.
